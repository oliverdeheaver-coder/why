Flood-o-matic

Three micro:bits, one radio chain, and an umbrella when the water rises.

What it does

Flood-o-matic is a water alarm made from three micro:bits that talk by radio. One sits by the water with a sensor, one passes the message along, and one stays somewhere dry and shows an umbrella when the water gets too high.

Try it

Reading: 0

Drag the slider to raise the water. Each second the sensor sends its reading by radio, and the alarm shows an umbrella above 500.

How it works

  1. Sensor micro:bit reads the water sensor on pin 0 (a number from 0 to 1023) and sends it by radio every second.
  2. Repeater micro:bit catches each message and sends it again, so the signal reaches further.
  3. Alarm micro:bit turns the message back into a number. Above 500 it shows an umbrella, otherwise a happy face.

All three use radio group 1, so they only listen to each other.
